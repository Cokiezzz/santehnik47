# Лендинг сантехнической службы

Статический шаблон на чистых HTML, CSS и JS.

## Где менять данные

- `index.html`:
  - название компании: `Чистый Сток`
  - телефон: `+7 999 000-00-00` и ссылки `tel:+79990000000`
  - услуги, преимущества, FAQ, email и город
- `styles.css`:
  - цвета в блоке `:root`
  - отступы, размеры, адаптивность
- `script.js`:
  - значения калькулятора в выпадающих списках берутся из `value` в `index.html`
  - текст после отправки формы
  - анимация фона первого экрана

## Как открыть

Откройте файл `index.html` в браузере. Сборка и сервер не нужны.

## Что подключить перед рекламой

- реальные контакты и город;
- обработку формы через CRM, Telegram, email или другой сервис;
- политику конфиденциальности, если вы собираете заявки;
- фактические цены, гарантии и юридические данные.
