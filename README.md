# Лендинг сантехнической службы

Статический шаблон на HTML, CSS и JS плюс простой CRM-сервер на Node.js для заявок в Telegram.

## Где менять данные сайта

- `index.html`:
  - имя и бренд мастера;
  - телефон и ссылки `tel:`;
  - мессенджеры: `wa.me`, `t.me` и кнопка `MAX`;
  - районы работы, услуги, блок об опыте, FAQ, email и текст формы.
- `styles.css`:
  - цвета в блоке `:root`;
  - отступы, размеры, карточки услуг и адаптивность.
- `script.js`:
  - логика мобильного меню;
  - отправка формы на `/api/leads`;
  - текст после отправки формы;
  - анимация фона первого экрана.

## Калькулятор

Ориентировочные цены меняются прямо в `index.html`:

- направление работ: список `select id="serviceType"`;
- срочность выезда: список `select id="urgency"`;
- сумма считается из чисел в атрибутах `value`.

## Telegram CRM

Сервер `server.js` делает четыре вещи:

- отдает сайт по HTTP;
- принимает заявки с формы на `/api/leads`;
- сохраняет заявки в `data/leads.json`;
- отправляет новые заявки в Telegram через вашего бота.

### Настройка бота

1. В Telegram откройте `@BotFather`.
2. Создайте бота командой `/newbot`.
3. Скопируйте токен бота.
4. Скопируйте `.env.example` в `.env`.
5. Вставьте токен в `TELEGRAM_BOT_TOKEN`.
6. Запустите сервер и напишите своему боту `/start`.
7. Бот покажет ваш `chat_id`.
8. Вставьте этот ID в `TELEGRAM_CHAT_ID` в `.env`.
9. Перезапустите сервер.

Пример `.env`:

```env
PORT=3000
TELEGRAM_BOT_TOKEN=1234567890:replace_with_bot_token
TELEGRAM_CHAT_ID=123456789
ENABLE_BOT_POLLING=true
TELEGRAM_DISABLED=false
```

### Запуск

```bash
npm start
```

После запуска сайт будет доступен по адресу:

```text
http://localhost:3000
```

### Команды бота

- `/start` — проверить подключение и узнать `chat_id`;
- `/leads` — показать активные заявки;
- `/all` — показать последние заявки;
- `/lead_1` — открыть заявку №1;
- `/done_1` — отметить заявку №1 обработанной.
- `/delete_1` — удалить заявку №1.

В Telegram также появится меню команд и кнопки в чате:

- `Активные заявки`;
- `Все заявки`;
- `Помощь`.

## Важно перед рекламой

- Не вставляйте токен Telegram-бота в HTML, CSS или JS.
- Не храните токен Telegram-бота в `server.js`; держите его только в `.env`.
- На хостинге запускайте сайт именно через `server.js`, иначе форма не сможет отправлять заявки.
- Файл `.env` и база `data/leads.json` добавлены в `.gitignore`.
- Для настоящего продакшена лучше добавить HTTPS, домен, политику конфиденциальности и резервное копирование заявок.

## Отзывы

Блок отзывов на сайте берет данные с серверного адреса:

```text
/api/reviews
```

Сейчас сервер читает отзывы из файла:

```text
data/reviews.json
```

Формат одного отзыва:

```json
{
  "source": "Avito",
  "author": "Иван",
  "rating": 5,
  "date": "2026-05-10",
  "text": "Текст отзыва",
  "url": "https://..."
}
```

### Как подключить свои отзывы

Самый надежный стартовый вариант:

1. Скопируйте реальные отзывы из Avito и Profi.
2. Вставьте их в `data/reviews.json`.
3. В поле `source` укажите `Avito` или `Profi`.
4. В поле `url` поставьте ссылку на публичный профиль или конкретный отзыв, если площадка дает такую ссылку.
5. Перезапустите сервер или обновите страницу.

### Avito

Если в вашем аккаунте Avito есть доступ к API отзывов, подключать его нужно только на сервере, не в `script.js`.

Схема такая:

1. Получить доступ к API в кабинете Avito для бизнеса или через поддержку Avito.
2. Получить `client_id`, `client_secret` и токен доступа по инструкции Avito.
3. Добавить эти значения в `.env`.
4. В `server.js` заменить чтение `data/reviews.json` в функции `readReviews()` на запрос к Avito API.
5. Привести ответ Avito к формату `source/author/rating/date/text/url`.

Токены Avito нельзя хранить в HTML, CSS или фронтенд-JS: их увидит любой посетитель сайта.

### Profi

Для Profi публичного API отзывов я не закладывал в код. Без официального API лучше не парсить страницу автоматически: верстка может измениться, а правила площадки могут запрещать такой сбор.

Практичный вариант:

- обновлять `data/reviews.json` вручную;
- добавить ссылку на профиль Profi в поле `url`;
- периодически переносить новые отзывы в JSON.
